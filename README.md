# RSS MP3 Downloader & Transcriber

RSSフィードからMP3ファイルをダウンロードし、OpenAI Whisperを使用して自動的に文字起こしを行うPythonツールです。

## 機能

- **RSSフィード取得**: 指定したRSS URLから音声ファイルの情報を取得・解析します。
- **ダウンロード管理**: 
  - チャンネルごとにフォルダを自動作成して保存します。
  - 単一ファイルまたは範囲指定での一括ダウンロードが可能です。
  - 既存ファイルのスキップ機能付き。
- **ID3タグ編集**: ダウンロードしたMP3ファイルにタイトル、アルバム（チャンネル名）、アーティスト等のメタデータを自動付与します。
- **文字起こし**: Whisperモデルを使用して、ダウンロードした音声ファイルをテキストファイル（`.txt`）に変換します。
- **リッチなUI**: `rich` ライブラリを使用し、進捗バーやテーブル表示で見やすいコンソール画面を提供します。

## 必要要件

- Python 3.10 以上
- FFmpeg
  - Whisperが音声ファイルを処理するためにシステムにインストールされ、パスが通っている必要があります。

## インストール

必要なPythonライブラリをインストールしてください。

```bash
pip install -r requirements.txt
```

※ `openai-whisper` はPyTorchなどの依存ライブラリもインストールするため、時間がかかる場合があります。

## 使い方

プロジェクトのルートディレクトリで以下のコマンドを実行します。
※ 初めての起動時は`openai-whisper`のモデルのダウンロードのため時間がかかります

```bash
python main.py
```

### メニュー操作

起動後、以下のメニューが表示されます。番号を入力して操作を選択してください。

1. **RSSフィードを取得**: RSSのURLを入力して解析します。最初にこれを実行してください。
2. **ファイル一覧を表示**: 取得したフィード内のダウンロード可能なエピソード一覧を表示します。
3. **ファイルをダウンロード(単一)**: リスト番号を指定して1つのファイルをダウンロードします。
4. **ファイルをダウンロード(範囲指定)**: 開始番号と終了番号を指定してまとめてダウンロードします。
5. **文字起こし実行**: ダウンロード済みの音声ファイルをスキャンし、Whisperで文字起こしを実行します。
   - 実行時に `--model` 引数でモデルサイズを指定可能です（デフォルトは `base`）。
   - 例: `python main.py --model small`
6. **終了**: アプリケーションを終了します。

## ディレクトリ構成

- `downloads/`: ダウンロードされたMP3ファイルと、生成された文字起こしテキストが保存されます（`.gitignore` 対象）。
- ソースコード: `main.py`, `rss_mp3_downloader.py`, `transcriber.py`
